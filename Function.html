Function Duel

Pick a function for each ball. Each ball shakes and fires its whole graph across the field, left and right, every time its cooldown runs out. A curve that touches another ball takes off hit points. Last ball standing wins.

Health ranges

A ball has the first value at full HP. The value moves in a straight line to the second value as its HP drops to 0. Each card shows the current values.
